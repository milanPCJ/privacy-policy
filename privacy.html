Politica de Privacidad

WhatsApp Finance Bot — Asistente financiero personal por WhatsApp

Ultima actualizacion: abril 2026

1. Que datos recopilamos

Recopilamos unicamente la informacion necesaria para el funcionamiento del servicio:

  • Numero de telefono: utilizado como identificador unico de usuario.
  • Mensajes de texto relacionados con finanzas: montos, categorias, comercios y notas que el usuario envia voluntariamente para registrar gastos e ingresos.
  • Correos electronicos de notificaciones bancarias (solo si el usuario conecta su Gmail): leemos unicamente correos de bancos chilenos para extraer datos de transacciones (monto, fecha, comercio). No accedemos a ningun otro tipo de correo.
  • Nombre y preferencias: nombre del usuario, tono de conversacion preferido, y configuracion de recordatorios.

2. Como usamos los datos

  • Registrar gastos e ingresos en el archivo Excel personal del usuario.
  • Generar reportes y graficos financieros personalizados.
  • Detectar transacciones bancarias automaticamente desde correos de notificacion.
  • Enviar recordatorios diarios si el usuario los activa.

No usamos los datos para publicidad, perfilamiento, ni ningun otro proposito fuera del servicio descrito.

3. Almacenamiento y seguridad

  • Los datos financieros se almacenan en un archivo Excel en Microsoft OneDrive, accesible unicamente por el usuario registrado.
  • Las credenciales de acceso a Gmail (refresh tokens) se almacenan encriptadas en el servidor.
  • El historial de conversacion se almacena localmente en el servidor y se limita a los ultimos 20 mensajes.
  • No almacenamos el contenido completo de los correos electronicos. Solo extraemos y guardamos los datos de la transaccion (monto, fecha, comercio).

4. Comparticion de datos con terceros

No vendemos, compartimos ni transferimos datos personales a terceros.

Los unicos servicios externos que procesan datos son:

  • WhatsApp Cloud API (Meta): para enviar y recibir mensajes.
  • Anthropic Claude API: para interpretar mensajes de texto (el contenido se envia para procesamiento de lenguaje natural; Anthropic no retiene los datos).
  • Google Gmail API: para leer notificaciones bancarias (solo lectura).
  • Microsoft OneDrive: para almacenar el archivo Excel del usuario.

5. Uso de datos de Google APIs

El uso y transferencia a cualquier otra aplicacion de la informacion recibida de las APIs de Google cumplira con la Google API Services User Data Policy, incluyendo los requisitos de Limited Use (Uso Limitado).

Especificamente:

  • Solo solicitamos el permiso gmail.readonly (lectura de correos).
  • Usamos este acceso unicamente para leer correos de notificaciones bancarias y extraer datos de transacciones.
  • No usamos los datos de Gmail para publicidad, estudios de mercado ni perfilamiento.
  • No compartimos los datos de Gmail con terceros, excepto segun sea necesario para el funcionamiento del servicio (procesamiento de lenguaje natural para interpretar el contenido del correo bancario).
  • No permitimos que humanos lean los correos del usuario, salvo con consentimiento explicito, por razones de seguridad, o para cumplimiento legal.

6. Control del usuario

  • Revocar acceso a Gmail: en cualquier momento desde myaccount.google.com/permissions o escribiendo "desconectar correo" al bot.
  • Eliminar datos: el usuario puede solicitar la eliminacion de sus datos enviando un mensaje al bot o contactandonos por email.
  • Acceso al Excel: el archivo Excel es propiedad del usuario y esta en su OneDrive personal.
  • Desactivar recordatorios: escribiendo "desactivar recordatorio" al bot.
